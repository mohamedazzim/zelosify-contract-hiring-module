## Proposed NSG Rule

**Note:** Azure CLI is not available on the VPS, and I cannot access the Azure portal. The user must apply this rule manually.

| Field | Value |
|---|---|
| NSG name | Unknown (requires Azure portal inspection) |
| Attached resource | VM network interface or subnet |
| Direction | Inbound |
| Protocol | TCP |
| Destination port |9443 |
| Action | Allow |
| Source | `Any` (presigned URLs are generated server-side; restricting source would break browser uploads from arbitrary IPs) |
| Priority | Lower number than any matching deny rule (e.g.,100) |
| Name | `allow-minio-presigned-api-9443` |

**Why Any source is unavoidable:** Presigned URLs are generated by the backend and returned to the browser. The browser then PUTs directly to MinIO. Since the client IP is unknown at presign time, the source must be Any.

**Rollback command:** Delete the NSG rule `allow-minio-presigned-api-9443` from the Azure portal or via Azure CLI.

**Alternative:** If the NSG change is not approved, browser uploads will not work. The backend S3 operations (AI recommendation) now work via the internal endpoint fix.
